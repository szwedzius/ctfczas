## ctfczas

Projekt, który ma służyć jako alternatywa do ctftime.org w celu sprawdzania jakie ctfy dzieją się w danym terminie, ale jak tak dłużej myślałem to w sumie może tam być dużo więcej.

Pomysły i czy są skończone:
- [ ] human bracket dla drużyn biorących udział
- [ ] ranking indywidualny z poszczególnie rozwiązanymi taskami i przesyłanymi (publicznymi) writeupami
- [ ] uploadowane materiały do nauki poszczególnych kategorii
- [ ] możliwość uploadu nagrań spotkania koła naukowego (s3 robi brrr)
- [ ] hostowanie ciekawszych znalezionych przez graczy zadań permanentnie (ctfd?) (za zezwoleniem autora)
